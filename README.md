**Lazuli** is a PocketMine-MP plugin designed to expand your server's building possibilities by adding a massive collection of missing vanilla block variants. From concrete slabs to obsidian fences, Lazuli introduces the blocks that builders have always wanted in the base game.

This plugin is proudly powered by **[Nexly](LIEN_VERS_NEXLY)**. By utilizing Nexly's robust API, Lazuli seamlessly registers and manages hundreds of custom blocks (slabs, stairs, fences, gates, and walls) while ensuring high performance and stability.

### Features
* **Massive Expansion:** Adds hundreds of missing variants for nature, nether, end, and stone blocks.
* **Colorful:** Full support for all 16 dye colors on blocks like Wool and Concrete.
* **Powered by Nexly:** Built on top of a solid foundation for optimal custom block handling.
